🧮 Calculator App

A simple and user-friendly Calculator Android application built using **Kotlin** and **Jetpack Compose**. The app provides a clean, modern interface for performing basic arithmetic calculations.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🎨 Clean and modern UI
- 📱 Built with Jetpack Compose
- ⚡ Fast and responsive user experience

🛠️ Tech Stack

- Language: Kotlin
- UI Framework: Jetpack Compose
- Platform: Android
- IDE:Android Studio

🚀 Getting Started

Prerequisites

- Android Studio
- Android SDK
- Basic knowledge of Kotlin

Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/Calculator-App.git
   ```

2. Open the project in Android Studio.

3. Wait for Gradle sync to complete.

4. Run the application on an Android emulator or physical device.
